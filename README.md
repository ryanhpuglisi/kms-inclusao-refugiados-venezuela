# Sistema KMS para Inclusão de Refugiados Venezuelanos

### Componente Curricular: Sistemas de Informação e Sociedade
Este sistema de informação foi desenvolvido como produto de uma Atividade Curricular de Extensão (ACE), com o objetivo de aplicar a tecnologia da informação como vetor de transformação social e garantia dos Direitos Humanos.

## 🛠️ Escopo Técnico e Arquitetura
O projeto consiste em um Sistema de Gestão do Conhecimento (KMS) responsivo, otimizado para o cenário pós-PC (acesso prioritário via smartphones por redes de dados móveis).

* **Módulo Léxico Bilíngue:** Banco de termos técnicos trabalhistas (CLT) traduzidos e contextualizados para mitigar a barreira idiomática e prevenir fraudes laborais.
* **Mural de Empregabilidade Justa:** Filtro de vagas de emprego locais que valorizam o idioma nativo do imigrante e exigem conformidade com o Artigo 170 da Constituição Federal (Existência Digna).
* **Infraestrutura:** Aplicação frontend leve em conformidade com as diretrizes de acessibilidade e ecoeficiência da Agenda 21.

## 👥 Impacto Comunitário Mensurado
* **Público atendido:** 26 refugiados venezuelanos em parceria com a Associação de Apoio ao Migrante.
* **Resultado:** Elevação do índice de segurança comunicativa laboral de 11,5% para 92,3%, com 17 encaminhamentos diretos para processos de seleção legítimos.
